A native select with the system's border and radius. It keeps the browser's own arrow and menu, so it works with every keyboard and screen reader.

- The consumer supplies the options and an `aria-label` when there is no visible label.
- 32px tall, 16px text, `radius`, `color-border`. The right padding is `spacing-6` to clear the native arrow.
- Under 640px a select inside a toolbar takes the full row and grows to 40px.
